<img width="311" height="765" alt="image" src="https://github.com/user-attachments/assets/6b275e5b-4da3-47e8-99c3-1fe16c82cf9a" /># Environmental Monitoring System using Bayesian Networks

This project is an application developed in C# for monitoring and predicting environmental quality using Bayesian networks.
The system analyzes factors such as temperature, humidity, wind, and human activity to estimate air and water quality. It uses probabilistic methods to model relationships between variables and handle uncertainty.
The application includes a graphical user interface built with Windows Forms, allowing users to input data and visualize results. Data and probability values are stored in JSON files.
Unit tests are implemented to ensure the correctness and reliability of the application.

## Technologies
- C#
- .NET (Windows Forms)
- Bayesian Networks
- JSON

## Features
- Environmental data analysis and prediction
- Probabilistic inference using Bayesian networks
- Graph-based modeling of variable relationships
- User-friendly graphical interface
- Data storage using JSON
- Unit testing for validation and reliability
